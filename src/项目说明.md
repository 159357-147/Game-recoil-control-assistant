# 游戏助手 - 操作说明

## 鼠标操作

### 基本功能
- **左键**：绑定压枪功能
- **鼠标侧键**：用来点击鼠标左键，但不会触发压枪功能

## 键盘快捷键

### 状态控制
- `Alt + H`：切换程序运行/暂停状态
- `Alt + J`：语音播报当前状态（运行/暂停）
- `Alt + G`：语音播报当前武器和倍镜配置

- `Alt + k`：重启程序
- `Ctrl + Alt`：退出程序

- `shift`：按下期间，截停鼠标拖动
- `tab`：触发截图识别

### 方案切换
- `字母区域 1`：切换到武器1号位识别的方案，同时程序状态切换为运行
- `字母区域 2`：切换到武器2号位识别的方案，同时程序状态切换为运行
- `字母区域其余数字按键`：程序状态切换为暂停

### 手动方案调整
- `小键盘区域 /`：切换到上一个父方案（武器类型）
- `小键盘区域 *`：切换到下一个父方案（武器类型）
- `小键盘区域 -`：切换到上一个子方案（倍镜类型）
- `小键盘区域 +`：切换到下一个子方案（倍镜类型）

### 数字键快速切换
- `数字键 1-9`：快速切换到对应序号的子方案（如果存在）


## 注意事项

- 程序可能需要以管理员权限运行
